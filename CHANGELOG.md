# Changelog

All notable changes to TabStash NVMe will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Planned
- Firefox browser support
- macOS support
- Snapshot encryption
- Automatic cleanup of old snapshots
- Native host auto-updates

## [0.1.0] - 2024-XX-XX

### Added
- Initial release
- Chrome extension for tab offloading
- Native host binary (Windows + Linux)
- NVMe storage backend
- Tab snapshot creation and restoration
- Health check UI in extension popup
- Windows installer script
- Linux installer script
- Comprehensive documentation
- Security and privacy documentation

### Known Limitations
- Chrome-only (Firefox support planned)
- Windows/Linux only (macOS planned)
- Requires manual native host installation
- No automatic updates for native host
- No encryption (local storage only)
