# Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels  
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## Icon Requirements

- **Format**: PNG with transparency
- **Style**: Professional, recognizable, related to tab management/storage
- **Colors**: Should work on both light and dark backgrounds
- **Design**: Simple, clear at small sizes

## Creating Icons

You can create icons using:
- Design tools (Figma, Adobe Illustrator, etc.)
- Online icon generators
- Hire a designer

For v0.1.0, placeholder icons can be used, but production should have proper branding.

## Placeholder Option

If you need placeholder icons immediately, you can:
1. Create a simple colored square with "TS" text
2. Use a generic storage/disk icon
3. Use a tab-related icon from icon libraries (with proper licensing)
